## Apa Itu **Looping**? 🤔

Dalam pemrograman, **looping** adalah sebuah konsep di mana kita ingin menjalankan **blok kode yang sama** berkali-kali secara otomatis, tanpa harus menulis kode berulang-ulang. Ibaratnya, kamu minta komputer buat mengerjakan tugas yang sama terus-menerus sampai kondisi tertentu terpenuhi. Contohnya, kalau kamu mau menghitung angka 1 sampai 10, kamu nggak perlu menulis `Console.WriteLine(1)`, `Console.WriteLine(2)`, dan seterusnya. Cukup pakai looping, komputer yang bakal ngulang-ngulang tugas itu buatmu! 🔁

Perumpamaannya:

- Bayangkan kamu sedang mengisi ulang kotak permen. Kamu bakal terus ngisi kotak itu sampai penuh, kan? Looping bekerja dengan prinsip yang sama: "Ulangi tugas ini **sampai kondisi tertentu terpenuhi**." Misalnya, “Ulangi isi permen sampai kotak penuh (misalnya, sampai ada 10 permen).”

### Mengapa Looping Penting?

Looping mempermudah kita dalam:

1. **Mengulang tugas yang sama** tanpa menulis kode berulang-ulang.
2. **Menghemat waktu dan tenaga**, terutama saat kita perlu melakukan sesuatu dalam jumlah banyak.
3. **Memanipulasi data dalam jumlah besar**, seperti mengambil data dari daftar (list) atau array.

## Jenis-Jenis **Looping** di C# 💻

Di C#, ada tiga jenis loop yang paling umum digunakan:

1. **For Loop**
2. **While Loop**
3. **Do-While Loop**

### 1. **For Loop**: 🔁 Looping dengan Jumlah Iterasi yang Jelas

**For Loop** biasanya digunakan kalau kita sudah **tahu pasti** berapa kali kita ingin melakukan perulangan. Contohnya, kamu ingin mencetak angka dari 1 sampai 10. Loop ini cocok digunakan karena kita sudah tahu jumlah perulangannya (sebanyak 10 kali).

#### Struktur Sintaks:

```csharp
for (inisialisasi; kondisi; update)
{
    // Blok kode yang akan diulang
}
```

#### Komponen Penting:

1. **Inisialisasi**: Di sini kita menetapkan **variabel awal** untuk memulai loop. Biasanya berupa variabel counter (misalnya `int i = 0`).
2. **Kondisi**: Kondisi ini adalah **penentu kapan loop berhenti**. Selama kondisi ini **true**, loop akan terus berjalan. Misalnya `i < 10` artinya loop akan terus berjalan selama nilai `i` masih kurang dari 10.
3. **Update**: Bagian ini biasanya digunakan untuk **mengubah nilai variabel** setelah setiap perulangan. Umumnya, nilai `i` di-increment (ditambah) setiap kali loop selesai dijalankan, misalnya `i++` (sama dengan `i = i + 1`).

#### Contoh Sederhana:

```csharp
for (int i = 1; i <= 5; i++)
{
    Console.WriteLine("Angka: " + i);
}
```

🟢 **Output:**

```
Angka: 1
Angka: 2
Angka: 3
Angka: 4
Angka: 5
```

**Penjelasan**:

- Loop ini dimulai dari `i = 1`.
- Akan terus berlanjut selama `i <= 5` (kondisi masih `true`).
- Setelah setiap iterasi, `i` ditambahkan 1 (`i++`), sehingga pada akhirnya `i` mencapai 6 dan loop berhenti karena kondisi `i <= 5` sudah tidak terpenuhi.

#### Kasus Penggunaan:

1. **Looping Array**:
   Jika kamu punya array buah dan ingin mencetak semua buahnya:

   ```csharp
   string[] buah = { "Apel", "Jeruk", "Mangga" };

   for (int i = 0; i < buah.Length; i++)
   {
       Console.WriteLine("Buah: " + buah[i]);
   }
   ```

   🟢 **Output:**

   ```
   Buah: Apel
   Buah: Jeruk
   Buah: Mangga
   ```

2. **Menghitung Total**:
   Misalkan kamu mau menghitung total angka dari 1 sampai 10:

   ```csharp
   int total = 0;

   for (int i = 1; i <= 10; i++)
   {
       total += i;  // Sama dengan total = total + i
   }

   Console.WriteLine("Total: " + total);
   ```

   🟢 **Output:**

   ```
   Total: 55
   ```

### 2. **While Loop**: ⏳ Looping Sampai Kondisi Berubah

Berbeda dengan **For Loop**, **While Loop** digunakan kalau kita **tidak tahu pasti berapa kali perulangan** akan dilakukan, tapi kita tahu **kondisi** kapan loop harus berhenti. Selama kondisi itu benar (`true`), loop akan terus berjalan.

#### Struktur Sintaks:

```csharp
while (kondisi)
{
    // Blok kode yang akan diulang
}
```

#### Contoh Sederhana:

Misal, kamu lagi makan permen dan akan terus makan sampai semua permen habis:

```csharp
int permen = 5;

while (permen > 0)
{
    Console.WriteLine("Makan 1 permen. Sisa permen: " + permen);
    permen--;
}
```

🟢 **Output:**

```
Makan 1 permen. Sisa permen: 5
Makan 1 permen. Sisa permen: 4
Makan 1 permen. Sisa permen: 3
Makan 1 permen. Sisa permen: 2
Makan 1 permen. Sisa permen: 1
```

**Penjelasan**:

- Loop ini akan terus berjalan selama `permen > 0`.
- Setiap kali perulangan, variabel `permen` akan dikurangi (`permen--`).
- Ketika `permen` mencapai 0, loop akan berhenti.

#### Kasus Penggunaan:

1. **Menunggu Input User**:
   Loop ini bisa berguna saat menunggu input yang valid dari user:

   ```csharp
   string password;

   while (true)
   {
       Console.Write("Masukkan password: ");
       password = Console.ReadLine();

       if (password == "12345")
       {
           Console.WriteLine("Password benar!");
           break;  // Keluar dari loop
       }
       else
       {
           Console.WriteLine("Password salah, coba lagi.");
       }
   }
   ```

2. **Mengambil Nilai Random**:
   Kamu bisa menggunakan `while` untuk terus melakukan sesuatu sampai kondisi tertentu terjadi:

   ```csharp
   Random random = new Random();
   int angka = random.Next(1, 10);  // Dapetin angka random dari 1 sampai 9
   int tebak = 0;

   while (tebak != angka)
   {
       Console.WriteLine("Tebakan saya: " + tebak);
       tebak = random.Next(1, 10);  // Update tebakan dengan angka baru
   }

   Console.WriteLine("Ketemu! Angkanya adalah: " + angka);
   ```

   Di sini, loop akan terus berjalan sampai tebakan kita cocok dengan angka yang dihasilkan oleh `Random`.

### 3. **Do-While Loop**: 🔄 Loop Minimal Sekali Dijalankan

**Do-While Loop** mirip dengan **While Loop**, bedanya adalah **blok kode akan dijalankan minimal satu kali** dulu sebelum kondisi diperiksa. Artinya, meskipun kondisi awalnya salah (false), perulangan tetap dijalankan satu kali.

#### Struktur Sintaks:

```csharp
do
{
    // Blok kode yang akan diulang
}
while (kondisi);
```

#### Contoh Sederhana:

Misalkan kamu mau terus memasukkan koin ke mesin minuman sampai terkumpul cukup koin untuk membeli minuman:

```csharp
int koin = 0;
int hargaMinuman = 5;

do
{
    koin++;
    Console.WriteLine("Masukkan koin. Total koin sekarang: " + koin);
}
while (koin < hargaMinuman);

Console.WriteLine("Minuman keluar!");
```

🟢 **Output:**

```
Masukkan koin. Total koin sekarang: 1
Masukkan koin. Total koin sekarang: 2
Masukkan koin. Total koin sekarang: 3
Masukkan koin. Total koin sekarang: 4
Masukkan koin. Total koin sekarang: 5
Minuman keluar!
```

**Penjelasan**:

- Blok kode dalam `do` akan dijalankan **sekali** dulu, baru kemudian kondisi `koin < hargaMinuman` dicek.
- Jika kondisi `true`, loop akan berjalan lagi; jika `false`, loop berhenti.

#### Kasus Penggunaan:

1. **Minimal Menjalankan Tugas Sekali**:
   Misalnya, meminta input user minimal satu kali sebelum mem

eriksa kondisinya:

```csharp
string input;

do
{
    Console.Write("Masukkan sebuah angka: ");
    input = Console.ReadLine();
}
while (input != "123");

Console.WriteLine("Angka benar!");
```

Dalam contoh ini, meskipun input pertama langsung benar, blok kode dalam `do` tetap akan dijalankan **minimal sekali**.

## Kesimpulan 📝

1. **For Loop**: Cocok digunakan jika kamu **sudah tahu** jumlah perulangan yang pasti.
2. **While Loop**: Digunakan saat kamu **belum tahu pasti** berapa kali perulangan, dan loop bergantung pada kondisi tertentu.
3. **Do-While Loop**: Digunakan saat kamu ingin menjalankan perulangan **minimal satu kali**, baru kemudian mengecek kondisi.
